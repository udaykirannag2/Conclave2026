# Topic 1 — 15-Minute Run of Show

Compressed from [`outline-30min.md`](outline-30min.md). Same framework, same takeaway — half the runway. The cuts: no full "what is a token" explainer, Inform and Optimize move faster, the live QR demo shrinks to a mention, and Operate stays the centerpiece because it's the personal, differentiated story nobody else in the room can tell.

Framework the audience takes home: **Inform → Optimize → Operate.**

| Time | Headline | Talking points |
|---|---|---|
| 0:00–1:00 | *"You're Paying for Something You Can't See"* | Cold open. Every AI feature carries a real, variable cost behind every single interaction — most people building AI products don't know what one query, one task, one tenant actually costs them. That's the gap this talk closes in 15 minutes. |
| 1:00–3:00 | *"Microsoft Lost $20 Per User Per Month — And That's Normal Now"* | The margin problem. Bessemer: classic SaaS runs 80-90% gross margin; AI-native companies run 50-60% — same metric, same investors, half the margin. Microsoft's GitHub Copilot is the canonical example: inference cost exceeded the subscription price. The gap isn't overhead. It's compute. If you're an investor, this is already showing up in the diligence numbers you're seeing; if you're a founder, this is your P&L whether you've modeled it yet or not. |
| 3:00–5:30 | *"The Math That Lied to Everyone: Why 10x Users Became 30x Cost"* | The core insight — the strongest "lean in" moment. One line on token cost mechanics: a model reads your question in parallel but writes its answer one token at a time, so output costs 3-5x more than input per token. That's the only 101 this talk needs. Then the real point: AI cost is *linear* in tokens — it never compounds on its own. But tokens-per-user is not fixed. It drifts, silently, for reasons nobody puts in a forecast: longer context windows as conversations age, wider retrieval as your RAG index grows, agent loops that call the model 5-10 times per user action instead of once. Multiply user growth by an unmodeled 3x drift in tokens-per-user, and 10x user growth becomes 30x cost growth — with a pricing model still built for the 10x world. |
| 5:30–6:00 | *"The Framework You're Taking Home: Inform, Optimize, Operate"* | Name the three-stage arc explicitly. This is the takeaway, not just a story — repeat it once, cleanly, before moving. |
| 6:00–7:30 | *"Stage 1 — Inform: You Can't Manage What You Can't See"* | You can't fix a cost you can't attribute. Self-diagnostic ladder: **Crawl** (<10% of spend attributable to a task, tenant, or feature) → **Walk** (60-80% attributable) → **Run** (>95%, cost-per-task and cost-per-tenant visible in near real time, with anomaly detection catching a spike same-day instead of at month-end billing). Ask the room silently: which rung are you actually on? |
| 7:30–9:30 | *"Stage 2 — Optimize: Where the Real Money Is"* | Three levers, fast: **Caching** — repeat context (system prompts, long documents) can hit ~90% off on a cache hit. **Batching** — 30-40% of most workloads are batch-eligible (non-interactive, can tolerate latency) and batch APIs run at 50% off. **Commitment math** — before buying reserved capacity, run one formula: `commitment cost ÷ on-demand cost = breakeven utilization %`. If you can't hit that utilization, the discount is a loss, not a saving. |
| 9:30–13:00 | *"Stage 3 — Operate: The Agent That Cost 21x More Than It Should Have"* | The centerpiece — slow down here, this is the story only this speaker can tell. An 8-step agent loop that re-sends its full context at every step can cost 21.5x what a single call would — and an unguardrailed retry policy pushes that further. Five controls that actually stop it: max depth, max tokens per task, retry limits, timeouts, an explicit fallback path. Personal proof, two data points: a real itemized per-reel cost breakdown from a shipped multi-agent video pipeline, and a $10M/year client engagement where loop caps plus a kill-switch made a 20-25% savings *stick* instead of drifting back within a quarter. |
| 13:00–13:30 | *"Try It Yourself"* | No live demo in 15 minutes — one line and a QR code: a token-cost calculator, take it with you, run your own numbers tonight. |
| 13:30–15:00 | *"One Question for Founders, One Question for Investors"* | Close. Founders: *"Which stage are you actually in — Inform, Optimize, or Operate?"* Investors: *"Ask a startup that question before you ask for the pitch deck."* CTA to the calculator and to a conversation after the talk. |
